# 分镜分析字段说明

每个分镜应包含以下字段，根据视频类型灵活取舍：

## 基础字段

- **时间码**：分镜开始和结束的时间点，格式 `00:00.00 - 00:05.00`。
- **截帧图片**：从视频中截取的代表帧，文件名带时间戳，如 `shot_0003_08.20s.jpg`。
- **画面描述**：客观描述画面中有什么，不加入解读。
- **主体/产品/人物**：画面核心是什么（人、产品、场景、文字）。
- **动作**：主体在做什么，或镜头本身有什么动作。

## 镜头语言字段

- **运镜方式**：
  - 固定镜头（Static）
  - 推（Push in）
  - 拉（Pull out）
  - 摇（Pan：水平 / Tilt：俯仰）
  - 移（Dolly / Truck）
  - 跟拍（Follow）
  - 手持（Handheld）
  - 航拍（Aerial）
  - 斯坦尼康（Steadicam）
  - 一镜到底（One-shot / Long take）

- **景别**：
  - 特写（Close-up, CU）
  - 近景（Medium close-up, MCU）
  - 中景（Medium shot, MS）
  - 全景（Full shot, FS）
  - 远景（Wide shot / Long shot）
  - 大远景（Extreme long shot, ELS）

- **构图**：
  - 中心构图、三分法、对称构图、框架构图、引导线、留白、俯拍、仰拍等。

## 视觉风格字段

- **光线与色彩**：
  - 光线方向：顺光、侧光、逆光、顶光、底光。
  - 光线性质：柔光、硬光、自然光、人工光、伦勃朗光、剪影。
  - 色调：冷暖、明暗对比、饱和度、单色/互补色。

- **情绪**：
  - 紧张、轻松、悬疑、温暖、孤独、兴奋、专业、亲切、高级感等。

## 复刻字段

- **复刻要点**：
  - 如果要重拍这个镜头，需要保留的关键元素是什么。
  - 包括：机位高度、镜头焦距、运动速度、演员动作、灯光位置、道具摆放、背景信息、后期特效等。

- **AI 提示词**：
  - 将分镜转化为可直接输入 AI 视频/图像生成工具的英文或中文提示词。
  - 建议结构：主体 + 动作 + 环境 + 光线 + 风格 + 镜头参数 + 情绪。

## 特殊场景补充

- **口播/真人出镜**：补充人物表情、眼神方向、手势、服装、妆发、背景布置。
- **产品展示**：补充产品角度、反光、材质、展示动作、信息图/字幕叠加。
- **文字/包装**：补充字体、动效、颜色、出现方式、停留时间。
- **转场**：说明转场类型（硬切、淡入淡出、叠化、划像、匹配剪辑、遮罩转场等）。
