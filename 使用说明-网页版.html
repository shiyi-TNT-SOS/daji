妲己拉片 — 使用说明

视频参考片结构化拆解工具
上传视频 → 自动截帧 → AI 视觉分析 → 生成暗黑仪表盘 HTML 报告 + ZIP 图片包

📦 什么是妲己拉片？

妲己拉片 是一个开源的视频分析工具，专为内容创作者、短视频运营、广告导演设计。

它能帮你：

  • 📸 自动截帧 — 把视频拆成关键帧和分镜图
  • 📊 生成总览图 — 视频整体节奏一目了然
  • 📝 12模块分析报告 — 从基础信息到AI提示词，全覆盖
  • 🌐 HTML报告 — 暗黑仪表盘风格，单文件离线可打开
  • 📦 ZIP图片包 — 所有关键帧+分镜帧打包，方便存档

🎯 适合谁用？

角色 使用场景
短视频运营 拆解爆款视频，学习分镜和节奏
内容创作者 分析竞品，提取可复刻的镜头语言
广告导演 快速生成故事板，给客户看分镜结构
AI视频创作者 生成AI平台提交版提示词（可灵/即梦/Runway）

🚀 快速开始

1️⃣ 安装依赖

pip install imageio-ffmpeg Pillow

✅ 推荐用 imageio-ffmpeg — 无需额外安装系统 ffmpeg，自动提供二进制。

❌ 如果你用系统 ffmpeg，确保已安装并能在命令行调用。

2️⃣ 放置 Skill 文件

把 video-lapian/ 文件夹放到：

~/.workbuddy/skills/video-lapian/

目录结构：

video-lapian/
├── SKILL.md              ← 技能说明（给AI看的）
├── requirements.txt       ← 依赖清单
├── README.md             ← 英文使用说明
├── 使用说明.md          ← 中文使用说明
├── assets/
│   └── report_template.md
├── references/
│   └── field_descriptions.md
└── scripts/
    ├── extract_frames.py      ← 截帧 + 场景检测
    ├── generate_overview.py   ← 生成总览图
    ├── generate_html.py       ← Markdown → HTML报告
    └── generate_zip.py       ← 打包图片ZIP

3️⃣ 使用方式

方式A：通过 AI 对话（推荐）

跟 AI 说：

妲己拉片，分析这个视频 C:/videos/ad.mp4

AI 会自动走完：

  1. 截帧 → 2. 分析 → 3. 生成报告 → 4. 呈现结果

方式B：命令行直接跑

# 1. 截帧
python ~/.workbuddy/skills/video-lapian/scripts/extract_frames.py "video.mp4" --out "video_分析"

# 2. 生成总览图
python ~/.workbuddy/skills/video-lapian/scripts/generate_overview.py "video_分析/关键帧" --out "video_分析/视频总览图.jpg" --title "视频总览"
python ~/.workbuddy/skills/video-lapian/scripts/generate_overview.py "video_分析/分镜详解" --out "video_分析/分镜总览图.jpg" --title "分镜总览"

# 3. 让AI分析并写报告（见下方"报告生成"）

# 4. Markdown转HTML
python ~/.workbuddy/skills/video-lapian/scripts/generate_html.py "video_分析/完整分析报告.md" --out "video_分析/完整分析报告.html"

# 5. 打包ZIP
python ~/.workbuddy/skills/video-lapian/scripts/generate_zip.py "video_分析" --out "video_分析/分析图片.zip"

2. HTML报告（完整分析）

12个模块按序排列：

模块 内容
1. 基础信息 时长、分辨率、帧率、分镜数
2. 视频总结 整体概括、核心卖点、情绪基调、目标受众
3. 视频总览 关键帧网格图（均匀采样）
4. 分镜总览 场景切换代表帧网格图
5. 内容结构 段落、时间码、内容定位、功能
6. 剧本拆解 旁白/文案、字幕节奏、BGM/音效
7. 有效分镜清单 序号、时间码、画面关键词、景别、运镜、情绪
8. 分镜详细拆解 每镜的截帧+8个分析字段
9. AI视频平台提交版 适合可灵/即梦/Runway的提示词
10. 单镜头官方提示 每个分镜的独立提示词
11. 分段秒脚本 按秒拆分的时间轴脚本
12. 最终全片串联提示 复刻整支视频的完整提示词

视觉风格：暗黑仪表盘（#05090d 背景 + #52e8ff 青色高亮）

🔧 高级功能

1. 调整分镜检测灵敏度

场景检测默认阈值 0.25（0-1之间，越小越敏感）。

  • 分镜太少 → 降到 0.20
  • 分镜太多 → 升到 0.30
python extract_frames.py "video.mp4" --out "video_分析" --scene-threshold 0.20

2. 纯分镜模式（只要干净网格图）

跟 AI 说：

只要分镜总览图，不要文字标注和时间戳

AI 会输出：

  • 完整分镜总览图_无标注.jpg（干净网格，按时间顺序排列）

3. AI视频平台提示词

报告第9-12模块专门为你生成：

模块 用途
AI视频平台提交版 可灵/即梦/Runway/Pika 等平台的直接提交格式
单镜头官方提示 每个分镜的独立提示词（文生图/图生视频）
分段秒脚本 按秒拆分的时间轴（画面+旁白+音效）
全片串联提示 复刻整支视频的完整提示词

⚠️ 注意事项

1. 只使用原始视频帧

❌ 不搞AI生成图 — 所有截帧图都是从视频里真实截出来的

❌ 不编造替代画面 — 如果视频质量差，帧也会差

✅ 可追溯 — 每张图文件名带时间戳（如 frame_0001_12.50s.jpg）

2. 分镜数不强制固定

✅ 按场景、机位、动作、主体或情绪变化自然切分

❌ 不会强行凑出"固定10个分镜"

✅ 一镜到底的视频，会补充分镜采样帧（保持每秒采样）

3. 首帧和尾帧必须真实

✅ 分镜总览图必须以真实首帧开始、真实末帧结束

✅ 对15秒以上的一镜到底视频尤其重要

✅ 始终导出 首帧.jpg 和 尾帧.jpg 并包含在ZIP中

🔍 故障排除

问题 解决方案
缺少 ffmpeg 安装 imageio-ffmpeg（pip install imageio-ffmpeg）或系统 ffmpeg
场景检测分镜太少 用 --scene-threshold 0.20 重跑 extract_frames.py
场景检测分镜太多 用 --scene-threshold 0.30 重跑 extract_frames.py
HTML图片不显示 检查 Markdown 中图片路径是否相对于报告文件正确
ZIP缺少图片 检查 分析目录/ 下是否有 关键帧/ 和 分镜详解/ 文件夹

📝 示例：完整工作流

AI 自动执行

1. 创建输出目录 summer_outfit_分析/
2. 截帧 + 场景检测
   → 关键帧/ (每秒1帧)
   → 分镜详解/ (场景切换帧)
   → metadata.json
   → frames_manifest.csv
   → shots_manifest.csv
3. 生成总览图
   → 视频总览图.jpg
   → 分镜总览图.jpg
4. 用视觉能力查看关键帧和分镜，写分析报告

5. Markdown转离线HTML
   → 完整分析报告.html (base64内联图片)
6. 打包图片
   → 分析图片.zip
7. 呈现结果
   → 聊天消息摘要
   → HTML报告（可离线打开）
   → ZIP图片包（可下载）

💡 使用技巧

1. 选择合适的视频

  • ✅ 有分镜变化的视频 — 广告、MV、短视频
  • ⚠️ 一镜到底的视频 — 会补充分镜采样帧，但分镜数少
  • ❌ 纯黑屏或静态图片视频 — 截帧无意义

2. 用于竞品分析

  1. 拉片 → 2. 看分镜详细拆解 → 3. 提取"复刻要点" → 4. 用AI提示词模块生成自己的版本

3. 用于AI视频创作

  1. 拉片 → 2. 看第9-12模块 → 3. 复制提示词 → 4. 提交给可灵/即梦/Runway
